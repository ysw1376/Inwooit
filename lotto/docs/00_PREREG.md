# 사전 등록 — 5등 당첨자 수를 이용한 구매 인기도 검정

작성 시각: 2026-09-29, **추가 데이터 수집 전**.
이 문서를 쓴 뒤에만 1223회 이전 등수별 당첨자 수를 수집한다.
아래 항목은 결과를 본 뒤 변경하지 않는다.

## 1. 배경 — 왜 새로 하는가

기존 인기도 분석은 **1등 당첨자 수**를 신호로 썼다. 회차당 평균 약 10명이라
노이즈가 압도적이어서 80% 검정력에 약 1,178~1,744회가 필요했고, 그래서 폐기됐다.

**5등 당첨자 수는 회차당 약 250만 명**이며, 당첨번호 6개 중 3개를 포함한 표가
몇 장 팔렸는지를 직접 알려준다. 포아송 상대오차는 약 0.06%다.

## 2. 이미 관찰한 탐색적 결과 (20회차, 1224~1243)

이 부분은 **탐색**이며 확증이 아니다. 숨기지 않고 기록한다.

- 5등 배수(= 실측 5등 당첨자 ÷ 판매게임수 ÷ 이론 2.244060%)의 표준편차 0.0331.
  포아송 노이즈(0.00061)의 **54배** → 구매 편향의 존재 자체는 확정적.
- 5등 배수 vs 12이하 번호 개수: 전체 20회 r=+0.478 (p=0.033),
  임계값 선택에 쓰지 않은 1228~1243 16회 r=+0.455 (p=0.077).
- 회귀 기울기 +0.0193 ± 0.0083 → 12이하 1개당 5등 당첨자 **+1.93%**.
- 대조: 1등 당첨자 수로 같은 검정 시 r=+0.067 (신호 없음).

## 3. 확증 검정 — 사전 지정

**주가설 (단측)**: 5등 배수는 당첨번호의 12 이하 개수가 많을수록 크다.
방향은 위 탐색 결과에서 정했으므로 단측 검정을 쓴다.

**주평가지표**
```
게임수 N_t = 판매액_t / 1000
5등배수 M_t = (W5_t / N_t) / [C(6,3)·C(39,3) / C(45,6)]
검정     M_t = α + β · n_le12_t + ε_t   의 β > 0
```

**판매액 복원**: `S_t = 16·B2_t + 2·(50,000·W4_t + 5,000·W5_t)`
(1224~1227회 4개 회차에서 실측 판매액과 오차 0.0000% 확인 완료)

**표본**: 새로 수집하는 회차 전체. 이월 배당 회차(1등풀/2등풀 > 6.01)는 제외.
1등 0명 회차는 유지. 1~87회는 배당 규칙이 달라 제외.

**판정**: 단측 p < 0.05 이면 신호 인정. 효과 크기는 95% 신뢰구간과 함께 보고.

**부차 분석** (사전 지정, 주판정에 영향 없음)
- 번호합을 공변량으로 추가했을 때 β의 변화 (기존 분석에서 문제됐던 교란)
- 4등 배수로 같은 검정 (신호의 일관성 확인)
- 시간 추세 보정 전후 비교

## 4. 결과 해석의 한계 — 미리 명시

- n_le12 라는 특징은 과거 8개 후보 중 1등 데이터로 고른 것이다.
  같은 회차의 5등 데이터로 검정하는 것은 **부분적으로만 독립**이다.
  완전 독립 구간은 1228회 이후뿐이다.
- 이 검정이 통과해도 확인되는 것은 **"사람들이 낮은 번호를 더 많이 산다"**이지,
  **"특정 필터가 기대수익을 얼마 올린다"**가 아니다. 금액 환산은 별도 단계다.
- 구매 편향이 확인돼도 1등 확률(25/8,145,060)은 달라지지 않는다.

## 5. 이 검정이 실패하면

β가 유의하지 않으면 인기도 기반 필터를 최종 폐기하고,
`U25_L1_MAXCOV` 운영 규칙을 그대로 유지한다. 다른 특징으로 재탐색하지 않는다.
