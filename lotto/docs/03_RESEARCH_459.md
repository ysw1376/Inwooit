## 3. 현재 필터는 신호의 일부만 잡고 있다

현재 3조건 필터를 통과하는 조합의 평균 인기도 점수는 전체 분포의 **29.2 백분위**다.
즉 "덜 인기 있는 쪽"으로 치우쳐 있지만, 인기도를 직접 기준으로 삼으면 더 잘할 수 있다.

시드 8개 평균, 겹침 ≤1, 번호 사용 ≤5:

| 방식 | 후보 비중 | 5등↑ 커버리지 | 몫배수 | 1등만 적용 시 |
|---|---|---|---|---|
| 필터 없음 | 100% | 50.89% | ×1.0049 | +1.2원 |
| **현재 3조건 필터** | 44.4% | 50.31% | ×1.0342 | +8.2원 |
| 인기도 하위 50% | 50.0% | **50.37%** | ×1.0480 | +11.5원 |
| 인기도 하위 40% | 40.0% | 50.24% | ×1.0552 | +13.2원 |
| 인기도 하위 30% | 30.0% | 49.92% | **×1.0688** | **+16.5원** |
| 인기도 하위 20% | 20.0% | 생성 실패 | — | — |

**인기도 하위 50% 컷은 현재 필터를 지배한다** — 커버리지가 오히려 약간 높으면서(50.37% vs 50.31%)
몫배수가 크다(×1.0480 vs ×1.0342). 하위 20%는 후보가 고번호에 몰려
번호 사용 ≤5 제약과 충돌해 25줄을 못 채운다.

## 4. 이 연구가 말하는 것과 말하지 않는 것

**말하는 것**
- 번호별 구매 선호는 실재하고, 459회로 정밀하게 추정되며, 9년간 안정적이다
- 사람이 고른 3조건 필터보다 추정 인기도를 직접 기준으로 쓰는 편이 낫다
- n_le12는 이 구조의 거친 근사였다 (검증 R² 0.38 vs 0.68)

**말하지 않는 것**
- 당첨 확률 향상. 1등은 여전히 25/8,145,060
- 몫배수를 실제 원화 이익으로 확정하는 것. 5등→1등 환산에는 감쇠계수 0.42308과
  곱셈적·균일 효과라는 모델 가정이 남아 있다
- 이 규칙을 바로 채택해도 된다는 것

## 5. 채택하려면 필요한 절차

인기도 기반 필터는 **새 규칙**이다. n_le12와 달리 모형 자체가 held-out 검증을 통과했지만
(R²=0.68), 그것과 "이 필터를 쓰면 얼마 이득"은 다른 명제다.

채택 전 필요한 것:
1. 컷 비율(30/40/50%)을 **결과를 보기 전에** 고정
2. γ 추정에 쓰지 않은 구간에서 몫배수 검증
3. 커버리지·2등 상한·번호 사용 제약과의 충돌 확인
