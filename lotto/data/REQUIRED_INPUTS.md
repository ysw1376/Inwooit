# 사용자가 제공해야 할 자료

| 파일 | 내용 | 비고 |
|---|---|---|
| `lotto.xlsx` | 1~1227회: 회차, 본번호 6개, 보너스, 1등 당첨금·당첨게임수, 2등 당첨금·당첨게임수 | 동행복권 엑셀 다운로드 |
| 1228회 이후 본번호·보너스 | 대화로 전달 또는 CSV | |

`lotto.xlsx` 열 순서: 회차, 번호1~6, 보너스, 1등당첨금, 1등당첨수, 2등당첨금, 2등당첨수

## 매주

| 자료 | 필수 | 출처 |
|---|---|---|
| 당첨번호 6개 + 보너스 | **필수** | 동행복권 |
| 등수별 당첨게임 수 (1~5등) | 권장 | https://lottohell.com/statistics/round-rank-winners/ |
| 총 판매금액 | 선택 | 없으면 배분규칙으로 역산 |

## 등수별 당첨게임 수 수집 요령

lottohell 페이지는 20회씩 페이지네이션된다. `?page=N` 으로 접근하되,
같은 URL 이 캐시될 수 있으므로 더미 파라미터(`&sort=round`)를 붙이면 우회된다.
페이지 N은 회차 `1244-20N` ~ `1263-20N` 을 담는다 (2026-09 기준).

형식: `회차,1등,2등,3등,4등,5등` 한 줄씩, `data/tier_winners_*.csv` 에 추가.

## 데이터 품질 점검

- 두 출처의 1등 당첨게임 수가 일치하는지 대조 (현재 459회 전부 일치)
- 이월 배당 회차(1등풀/2등풀 > 6.01) 제외
- 원자료가 전부 0인 회차 제외 (1106회가 그런 사례)
- 1~87회는 배당 규칙이 달라 제외
